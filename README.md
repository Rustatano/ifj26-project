# Setup

## Step 1
Install docker.

## Step 2
Clone the repository.

```git clone git@github.com:Rustatano/ifj26-project.git```

## Step 3
Open VS Code in root of the repository.

## Step 4
Locate at bottom left corner of the IDE is a small icon that looks simillar to this: ```><```. It is called "Open a remote window".

## Step 5
Click on the button and select option "Reopen in container".

## Step 6
Wait. It might take a few minutes (depends on your internet speed). It's initial setup, next time it will be instant.

## Step 7
Should be good to go.

## Step 8
Remember to open the repository in container next time you open VS Code.
